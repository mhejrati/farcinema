# Farcinema logo files

Wordmark: FARCINEMA in tracked capitals (Montserrat Bold outlines, converted to paths, so no font is needed) with the C drawn as an open amber outline.

Colors: ink #1b1a11 · cream #ece0d5 · amber #d9944f

## SVG (vector, use these wherever possible)
- farcinema-wordmark-on-dark.svg — cream letters, amber C, transparent background. For dark backgrounds.
- farcinema-wordmark-on-light.svg — ink letters, amber C, transparent background. For light backgrounds.
- farcinema-wordmark-mono-cream.svg / farcinema-wordmark-mono-ink.svg — single color versions.
- farcinema-icon.svg — the open C on an ink rounded square (app icon, avatar, favicon).
- farcinema-icon-transparent.svg — the open C alone.

## PNG (high resolution)
- farcinema-wordmark-on-dark@4000.png, farcinema-wordmark-on-light@4000.png — 4000 px wide with background.
- farcinema-wordmark-persian-on-dark@4000.png — with فارسینما beneath.
- farcinema-wordmark-cream-transparent@3200.png, farcinema-wordmark-ink-transparent@3200.png — transparent.
- farcinema-icon@1024.png — 1024 px icon.

Below about 24 px tall the open C fills in; use the mono versions there.
